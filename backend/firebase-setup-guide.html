🔥 Firebase Setup Guide

Step-by-step instructions to enable real SMS OTP verification for ChatApp

1

Go to Firebase Console

Open the Firebase Console in your browser and sign in with your Google account.

🔗 Open Firebase Console
Already have a project? Select it and skip to Step 3.
New project? Click "Add project" below.
2

Create a Firebase Project (if needed)

  1. Click "Add project"
  2. Enter project name (e.g., chatapp-prod)
  3. Disable Google Analytics (optional)
  4. Click "Create project"
  5. Wait for setup, then click "Continue"
⚠️ Important: You MUST upgrade to Blaze (Pay-as-you-go) plan to use Phone Authentication with real SMS. Free Spark plan does NOT support outbound SMS.

Go to: Project Settings → Usage and billing → Modify plan → Blaze
3

Enable Phone Authentication

  1. In the left sidebar, click Build → Authentication
  2. Click "Get started"
  3. Go to "Sign-in method" tab
  4. Click on Phone
  5. Toggle Enable to ON
  6. Click Save
✅ Phone Authentication is now enabled. Firebase will send real SMS OTP codes to any phone number worldwide.
4

Generate Service Account Key (JSON)

  1. Click ⚙️ gear icon next to "Project Overview" → Project settings
  2. Go to the "Service accounts" tab
  3. Select "Node.js" in the Admin SDK configuration snippet
  4. Click "Generate new private key"
  5. Click "Generate key" in the popup
  6. A .json file will download to your computer
📂 The downloaded JSON file will look like:
chatapp-prod-firebase-adminsdk-xxxxx-xxxxxxxxxx.json
5

Open the Downloaded JSON File

Open the downloaded JSON file with Notepad or any code editor. It will look like this:

{
  "type": "service_account",
  "project_id": "chatapp-prod-12345",
  "private_key_id": "abc123...",
  "private_key": "-----BEGIN PRIVATE KEY-----\nMIIEvQIBAD...",
  "client_email": "firebase-adminsdk-xxx@chatapp-prod-12345.iam.gserviceaccount.com",
  "client_id": "1234567890",
  // ... more fields
}
6

Copy Values into .env File

Open the file backend/.env and update these values from your downloaded JSON:

# ──── COPY FROM JSON ────────────────────────────────────────

# From "project_id" in JSON:
FIREBASE_PROJECT_ID=chatapp-prod-12345

# From "client_email" in JSON:
FIREBASE_CLIENT_EMAIL=firebase-adminsdk-xxx@chatapp-prod-12345.iam.gserviceaccount.com

# From "private_key" in JSON — keep the \n characters!
FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nMIIEvQIBAD...\n-----END PRIVATE KEY-----\n"

# From Firebase Console → Storage → gs://YOUR-BUCKET.appspot.com
FIREBASE_STORAGE_BUCKET=chatapp-prod-12345.appspot.com

# ──── SWITCH TO LIVE OTP ─────────────────────────────────────
OTP_DEV_MODE=false
⚠️ PRIVATE_KEY warning: The private key contains \n newline characters. Make sure you copy the entire value including these characters and wrap it in double quotes in the .env file.
7

Get Firebase Storage Bucket URL

  1. In Firebase Console, click Build → Storage
  2. Click "Get started" (if first time)
  3. You will see your bucket URL: gs://chatapp-prod-12345.appspot.com
  4. Copy just the bucket name: chatapp-prod-12345.appspot.com
  5. Paste it into FIREBASE_STORAGE_BUCKET in .env
8

Restart Backend Server

After updating .env, restart the backend server to apply changes:

# In terminal, navigate to backend folder:
cd "c:\xampp\htdocs\chat app\backend"

# Kill any running server:
npx kill-port 5000

# Start server again:
npm run dev
✅ You will see in logs: "Firebase Admin SDK initialized"
⚠️ OTP DEV MODE warning will disappear — you're now using LIVE OTP!
9

Test Live SMS OTP

Open the app and enter your real mobile number. Firebase will send a real SMS within seconds.

  1. Open http://172.20.10.2:8081
  2. Enter your real mobile number (e.g. +92 300 1234567)
  3. Tap Continue
  4. You will receive a real SMS with a 6-digit code
  5. Enter it and tap Verify
🎉 Live OTP is working! Your ChatApp is now using real Firebase SMS authentication.
